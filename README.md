## 📘 Projeto MesclaInvest

Aplicativo mobile desenvolvido como parte do Projeto Integrador 3 (PI3) do curso de Engenharia de Software da PUC-Campinas (2026).<br><br>

O MesclaInvest é uma plataforma digital que simula um ambiente de investimento em startups vinculadas ao ecossistema Mescla da Universidade.<br><br>

O sistema permite que usuários visualizem startups, acompanhem informações institucionais e realizem compra e venda simulada de tokens representativos de participação digital nos projetos.<br><br>

O objetivo do projeto é proporcionar experiência prática em arquitetura de software, desenvolvimento mobile, backend com regras de negócio e modelagem de dados utilizando tecnologias modernas.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 🚀 Funcionalidades principais

🔐 Autenticação de usuário (cadastro com e-mail, CPF, telefone e recuperação de senha)<br>
🔑 Autenticação multifator (MFA/2FA) opcional<br>
🚀 Catálogo de startups com classificação por estágio (Nova, Em operação, Em expansão)<br>
📄 Visualização de sumário executivo, estrutura societária e capital aportado (simulado)<br>
❓ Envio de perguntas públicas aos empreendedores<br>
💰 Balcão de negociação para compra e venda simulada de tokens<br>
💳 Carteira digital com saldo fictício em reais<br>
📊 Dashboard de valorização dos tokens (diário, semanal, mensal, 6 meses e YTD)<br>
📈 Registro e histórico de transações simuladas

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 🛠️ Tecnologias utilizadas

Backend: Node.js (versão LTS) – TypeScript/JavaScript<br>
Frontend Mobile: Flutter – Dart<br>
Banco de Dados: Firebase Firestore (NoSQL)<br>
IDE: Visual Studio Code / Android Studio<br>
Versionamento: Git + GitHub
